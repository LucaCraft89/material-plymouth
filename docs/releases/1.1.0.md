# Material Plymouth 1.1.0

The settings for the boot splash now appear on **Material Boot's new installer screen** (material-boot-core 1.1.0), so you choose them while installing instead of editing a file afterwards. The splash itself is unchanged.

## What's new
- **Asked on the screen:** the **loading bar** (keeps running, or fills as the boot progresses), **how much moves** (full, calm, or still; each with a one-line description), and whether you will add `splash` to the kernel command line yourself (by default the installer adds it, and puts it back on removal).
- **Still scriptable.** Every answer is also an option or a setting (`--plymouth-no-cmdline`, `PLYMOUTH_BAR`, `PLYMOUTH_MOTION`), and the screen's summary prints the exact command that does the same without it.

## Good to know
- Works with material-boot-core 1.0.x too (the questions are not shown there; the options work as before). The screen is part of **material-boot-core 1.1.0**.
- Installing does nothing to how you boot until you run `material-boot plymouth apply`, as before.

## How we tested it (and what we didn't)
The questions are checked against the real manifest on every change, and the screen was driven end to end in a container for GRUB; Plymouth's questions are checked as data and through the same screen code, but **the Plymouth part was not installed through the screen in a container** in this release.

**Not tested yet:** a real computer (real graphics hardware, firmware, an encrypted root disk), other terminals than xterm-compatible ones, and immutable systems.
